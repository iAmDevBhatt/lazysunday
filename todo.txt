LAZYSUNDAY — DEPLOYMENT CHECKLIST
==================================

STEP 1 — Copy project to server and build the Docker image
----------------------------------------------------------
  Copy the project folder to your server, then:

    cd /path/to/lazysunday
    docker compose up -d --build

  On first run the container automatically seeds /lazysunday/config.json
  from the baked-in default if it doesn't exist yet.

  Verify container is running:
    docker compose ps
    docker compose logs -f
    curl http://localhost:3010/api/config


STEP 2 — Host folder structure on your server
----------------------------------------------
  The following folders are mounted as Docker volumes:

    /lazysunday/
    ├── config.json       ← auto-created on first run, edit to customise
    ├── backgrounds/      ← drop background images here (jpg/png/webp etc.)
    └── covers/           ← drop album art here (filename must match track name)

    /mnt/dragon_hoard/Music/   ← your music library (read-only mount)

  Changes to config.json are picked up live — no restart needed.
  New background images appear on next browser page load.


STEP 3 — config.json quick reference
--------------------------------------
  Key settings to change after first run:

    "siteTitle"   — the large heading shown on the page (Hindi or any text)

    "music.type"  — "local" (default) or "youtube"
    "music.local.path" — path to your music folder (already set to
                         /mnt/dragon_hoard/Music)
    "music.youtube.playlistUrl" — paste a YouTube playlist URL here
                                  (requires yt-dlp on the host)

    "backgrounds.intervalSeconds" — how long each background image shows
    "backgrounds.images"          — leave as [] to auto-scan the
                                    backgrounds/ folder, or list specific
                                    filenames/URLs to control order


STEP 4 — Create a Proxy Host in Nginx Proxy Manager
----------------------------------------------------
  Two options depending on your setup:

  OPTION A — NPM on same Docker network (recommended, no exposed port):
    1. Find your NPM network name:
         docker network ls
    2. In docker-compose.yml uncomment the networks block and set the name
    3. Comment out the ports block
    4. Rebuild: docker compose up -d --build
    5. In NPM: Forward Hostname = lazysunday, Port = 3010

  OPTION B — Expose port (simpler):
    Keep ports: "3010:3010" in docker-compose.yml
    In NPM: Forward Hostname = your server IP, Port = 3010

  NPM proxy host settings:
    Domain Names         : music.yourdomain.com
    Scheme               : http
    Cache Assets         : OFF
    Block Common Exploits: ON
    Websockets Support   : OFF

  Enable SSL on the SSL tab — let NPM issue a Let's Encrypt cert.


STEP 5 — Advanced tab in NPM (required — paste exactly as-is)
--------------------------------------------------------------
  Without this, NPM buffering breaks audio seeking and the online counter.

  ---
  location /audio/ {
      proxy_pass http://lazysunday:3010;
      proxy_buffering        off;
      proxy_read_timeout     3600s;
      proxy_send_timeout     3600s;
      proxy_connect_timeout  10s;
      proxy_http_version     1.1;
      proxy_set_header       Connection "";
  }

  location /api/online/stream {
      proxy_pass http://lazysunday:3010;
      proxy_buffering        off;
      proxy_cache            off;
      proxy_read_timeout     3600s;
      proxy_http_version     1.1;
      proxy_set_header       Connection "";
      proxy_set_header       X-Accel-Buffering no;
  }

  location / {
      proxy_pass http://lazysunday:3010;
      proxy_http_version     1.1;
      proxy_set_header       Host              $host;
      proxy_set_header       X-Real-IP         $remote_addr;
      proxy_set_header       X-Forwarded-For   $proxy_add_x_forwarded_for;
      proxy_set_header       X-Forwarded-Proto $scheme;
  }
  ---

  Note: if using Option B (exposed port), replace lazysunday:3010
  with your-server-ip:3010 in all three proxy_pass lines above.

USEFUL COMMANDS
---------------
  Start / stop:
    docker compose up -d --build
    docker compose down

  View logs:
    docker compose logs -f

  Rebuild after code change:
    docker compose up -d --build

  Debug backgrounds not showing:
    curl http://localhost:3010/api/debug/backgrounds

  Open a shell inside the container:
    docker exec -it lazysunday sh
